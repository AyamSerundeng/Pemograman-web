## Deskripsi

Repository ini berisi kumpulan tugas, praktik, dan proyek yang dikerjakan selama perkuliahan Pemrograman Web. Fokus utama mencakup pengembangan aplikasi web menggunakan HTML, CSS, JavaScript, serta teknologi pendukung lainnya yang dipelajari di kelas.

Tujuan repository ini adalah mendokumentasikan proses pembelajaran, menyimpan hasil kerja secara terstruktur, dan memudahkan evaluasi perkembangan kemampuan dalam membangun aplikasi web.
